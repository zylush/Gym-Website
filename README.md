To view program, Install XAMPP.
- Download the code
- Transfer the file to xampp\htdocs
- "start" mysql & apache
- Search website "http://localhost/foldername/index.php. The foldername is the designated folder where the code files is stored (not htdocs), name can be anything in ur localmachine
- When viewing the code, retype index.php to dashboard.php to view the program
